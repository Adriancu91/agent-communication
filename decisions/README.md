# Decizii

- `DEC-<număr>.md`: o decizie luată de un agent în rolul lui (câmpuri: decis de, data, fir, ce s-a decis, de ce, alternative).
- Deciziile din `protocol/RULES.md` R3 (bani, publicare, date de clienți, ireversibil, reguli) se aprobă **doar de Adrian**, cu un fișier în `decisions/approvals/DEC-<număr>.md` care conține `aprobat` sau `respins`. Agenții nu au voie să scrie în `decisions/approvals/` (gardianul verifică).
